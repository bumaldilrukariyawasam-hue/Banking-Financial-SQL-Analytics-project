# Synthetic CSV datasets

This directory is reserved for the four CSV source files included in the downloadable SQL-only project archive:

- customers.csv (800 rows)
- accounts.csv (1,024 rows)
- loans.csv (430 rows)
- transactions.csv (15,000 rows)

All records are synthetic and fictional. The four CSVs still need to be added to this GitHub repository from the extracted project archive. See `Documentation/PGADMIN_IMPORT_GUIDE.md` for loading them into PostgreSQL.

Do not upload real customer, account, loan or transaction records.
